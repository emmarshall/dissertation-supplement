# Dissertation Supplement

Supplementary tables, figures, and analyses for Emma W. Marshall's dissertation, *What to Suspect When They're Expecting: Abortion Ambiguity, Hindsight Bias, and Probable Cause Determinations in Pregnancy Loss Investigations After* Dobbs (University of Nebraska–Lincoln, 2026).

**Read it online:** <https://emmarshall.github.io/dissertation-supplement/>

The supplement has one part for each study: Pilot Study 1, Pilot Study 2, Study 1, and Study 2. The `docs/` folder holds the rendered HTML book. To read it offline, download the repository and open `docs/index.html`.

## Preregistrations

The four studies were preregistered on the Open Science Framework.
