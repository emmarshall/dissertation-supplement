Notes shared by tables of this section.

  • Tables 2-S9.1 to 2-S9.5: N = 320 (Stereotypical, None, n = 55; Stereotypical, SMA, n = 52; Stereotypical, NCM, n = 60; Non-stereotypical, None, n = 52; Non-stereotypical, SMA, n = 50; Non-stereotypical, NCM, n = 51).
  • Tables 2-S9.1 to 2-S9.5: In the sensitivity analysis, N = 212 (Stereotypical, None, n = 32; Stereotypical, SMA, n = 33; Stereotypical, NCM, n = 45; Non-stereotypical, None, n = 36; Non-stereotypical, SMA, n = 29; Non-stereotypical, NCM, n = 37).

  • Tables 2-S9.2 and 2-S9.3: The registration requires an admissible, converged solution for an original-sample result (registered analysis supplement).
